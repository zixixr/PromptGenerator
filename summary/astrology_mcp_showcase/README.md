### 场景2: 社交媒体内容创作

**推荐素材来源**:
- 深夜倾诉类对话 → 制作"凌晨2点,还有我在听你说"主题内容
- 考试压力类对话 → 制作"比父母更懂你的学习伙伴"主题
- 职业规划类对话 → 制作"转行不慌,摩羯陪你算清账"主题

**内容形式**:
- 小红书图文: 截取2-3轮精华对话,配AI形象插图
- 抖音短视频: 真人配音演绎对话片段,展示"冷静但温暖"的摩羯人设
- 微博长图: 展示完整案例,附上用户评价(需征得同意)

---

### 场景3: KOL测评/媒体采访

**提供材料**:
- 发送`00_MASTER_SUMMARY.md`作为产品背景资料
- 选择3-5个不同场景的完整案例供测评者体验
- 重点标注MCP功能案例(有星盘分析/运势查询的对话)

**测评引导建议**:
1. 让测评者先带着真实问题与AI对话15分钟
2. 再展示这份文档包,对比测评者自己的体验
3. 引导对比维度:
   - vs Character.AI / Replika (纯聊天AI)
   - vs 测测/准了 (传统占星APP)

---

### 场景4: 销售资料/产品手册

**可直接引用的数据** (来自MASTER_SUMMARY):
- 30个真实对话,平均10.4轮深度对话
- 22个深度对话(10轮以上),占比73%
- 15个对话展示了Astrology MCP专业功能
- 用户年龄段17-31岁,覆盖学生/职场新人/白领

**核心卖点提炼**:
1. **情感陪伴能力**: "有我呢"式的平静守护,不煽情但有温度
2. **星座专业度**: 集成Swiss Ephemeris精准星盘计算
3. **性格一致性**: 摩羯座AI展现"傲娇可靠"人设,不是万能回答机
4. **实体化体验**: 毛绒玩具+AI对话,可带在身边的陪伴

2. 对外展示时建议隐去真实姓名,使用"用户A""17岁学生"等代称
3. 如需制作视频/音频内容,务必获得相关授权

1. 这些对话来自AI与AI的模拟对话,非真实用户
2. 对外宣传时可用"基于真实场景模拟"的表述
