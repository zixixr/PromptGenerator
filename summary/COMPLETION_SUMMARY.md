- **Endpoint**: http://127.0.0.1:8888
- **Session Creation**: `POST /sessions` (returns session_id)
- **Message Sending**: `POST /sessions/{session_id}/messages`
- **Total API Calls**: ~235+ successful requests

### Template System
Variables replaced: `{device_name}`, `{user_name}`, `{birthday}`, `{birth_location}`, `{sun}`, `{moon}`, `{ascendant}`, `{time}`, `{location}`

- Fixed HTTP status code mismatch (200 vs 201)
- Fixed response field name (`response` → `assistant_response`)
- Handled script timeout with continuation script
